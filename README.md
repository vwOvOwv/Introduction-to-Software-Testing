# 软件测试导论小组作业
该 repo 存放了北京大学 2026 年春季学期软件测试导论的相关实验代码。

## 实验流程

实验流程按照文件名排序：

`1_scan.py`：从 Apache Commons Lang 的 Git 历史中扫描候选提交。我们关注同时修改生产代码和测试代码的提交，并将每个提交整理成提交前版本 A 与提交后版本 B。

`2_filter.py`：对候选提交进行过滤，去除合并提交、纯格式修改、仅测试修改等不适合实验的样本，并优先保留生产类和测试类严格对应的样本。

`3_verify.py`：在 B 版本上运行原始 Maven 测试，确认筛选出的样本本身可以正常编译和测试，避免后续实验受到不可复现样本的影响。

`4_run.py`：调用大语言模型生成新的测试文件。模型输入主要包括 A 版本测试、相关代码变化和上下文信息；生成结果会被合并回项目中，并通过 Maven 运行验证。

`5_analyze_results.py`：统计模型生成实验的整体结果，包括成功生成数量、Maven 通过率、失败类型等，用于分析模型在测试维护任务上的基本表现。

`6_compare_similarity.py`：将模型生成的测试与 B 版本中人类开发者实际提交的测试进行静态相似度比较，关注测试方法名、增删改测试方法、断言数量和断言类型等指标。

`7_measure_quality.py`：进一步评估测试质量，比较模型测试与人类测试在覆盖率、变异测试分数等传统测试指标上的差异。

整体来看，本实验先构建真实软件演化样本，再让模型尝试补全测试更新，最后从“能否通过测试”“是否接近人类修改”“测试质量如何”三个角度进行评估。
